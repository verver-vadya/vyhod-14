# Выход 14 — сайт визового центра

Концепт для портфолио: сайт вымышленного визового центра «Выход 14» (Санкт-Петербург, Лиговский пр., 50, у метро «Площадь Восстания»). Метафора — аэропорт: на первом экране табло вылетов с перекидными буквами, страны оформлены как посадочные талоны, путь от заявки до визы — как маршрут с остановками, штампы ставятся в паспорт по мере прокрутки.

- Превью: https://verver-vadya.github.io/vyhod-14/ (после включения GitHub Pages)
- Стек: [Astro](https://astro.build), на выходе обычные HTML-страницы и немного JavaScript; сделан из [site-template](https://github.com/verver-vadya/site-template).
- Шрифты: Inter Tight и JetBrains Mono (OFL), лежат в `src/fonts/`.

## Страницы

| Адрес | Что там |
| --- | --- |

| `/vizy/` | все 10 стран талонами с фильтром «Шенген / Азия / электронные визы» |
| `/vizy/italiya/` и ещё 9 стран | срок, сбор, документы, где подают, пакеты с ценами, вопросы, заявка с уже выбранной страной |
| `/uslugi/` | пакеты «Документы», «Под ключ», «Срочно», таблица цен по странам, услуги отдельно, оплата |
| `/status/` | проверка заявки по номеру: табло показывает этап (в концепте этап выбирается по номеру) |
| `/o-nas/`, `/kontakty/` | об офисе и правилах работы; схема от метро, как дойти, контакты |
| `/zayavka/` | заявка; страна приходит из ссылки (`/zayavka/?strana=italiya`) |
| `/privacy/`, 404 | политика конфиденциальности (каркас по 152-ФЗ) и табло «Выход 404 — отменён» |

## Как устроено табло

Каждая буква — четыре половинки (верх и низ старой и новой буквы). Смена буквы — поворот половинок по оси X через Web Animations API, перед нужной буквой пролетает несколько случайных (`src/scripts/flap.ts`). На сервере табло уже собрано с текстом (`src/components/Flap.astro`), поэтому без JavaScript и для поисковиков оно читается сразу. После заставки строки заполняются по очереди, потом каждые 4 секунды одна строка меняется на следующую страну (`src/scripts/home.ts`). На телефоне видны две колонки и 4 строки, на низких экранах — 3 строки. При «уменьшить движение» буквы меняются сразу, без переворота.

Погода в городах берётся с [Open-Meteo](https://open-meteo.com), курс евро — с зеркала ЦБ [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru); если они недоступны, виджеты просто не показываются.

## Заявка

Формы отправляются через [Formspree](https://formspree.io): вписать адрес формы в `formAction` в `src/data/site.ts` вместо `YOUR_FORM_ID`; пока его нет, форма честно пишет, что не подключена. Formspree хранит данные за рубежом: для российского визового центра лучше Telegram-бот или свой обработчик на российском сервере (152-ФЗ, 242-ФЗ).

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:4321, страница обновляется сама
npm run build    # готовый сайт в папке dist
```

## Автопроверка

`npm run check` собирает сайт и проверяет все страницы из `dist`: битые ссылки, кнопки без наведения и нажатия, форму, меню, ошибки в консоли, мелкие зоны нажатия, наложения и горизонтальную прокрутку от 320 до 2560 px, анимации свойств, которые пересчитывают страницу. В каждом pull request проверка запускается сама (`.github/workflows/check.yml`), отчёт и скриншоты лежат в артефакте `screenshots`.

## Публикация

Превью на GitHub Pages собирается при каждом пуше в `main` (`.github/workflows/pages.yml`): включить в Settings → Pages → Source: GitHub Actions. Для настоящего визового центра с российской аудиторией сайт публикуется на российском хостинге (Timeweb, Beget, Reg.ru): туда загружается содержимое папки `dist`.
